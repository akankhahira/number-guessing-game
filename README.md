# Number Guessing Game 🎯

A simple number guessing game developed using the C programming language.

## 🎮 How the Game Works

The computer generates a random number, and the player has to guess it.

The program gives hints depending on whether the guessed number is:
- high
- low
- Correct

## 🛠️ Technologies Used
- C
- GCC
- VS Code

## ▶️ How to Run
Compile the program:

```bash
gcc guessing_number.c -o guessing_number
